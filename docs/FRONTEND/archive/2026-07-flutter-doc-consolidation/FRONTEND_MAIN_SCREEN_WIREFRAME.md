# TransVortex 首屏白描框架

本文档定义首屏第一轮低保真结构。

它不描述颜色、插画细节、素材风格和最终 CSS。它只回答：

- 首屏有哪些对象。
- 这些对象的主次和位置关系。
- 空、就绪、展开、运行、完成、失败状态如何变化。
- 哪些内容默认隐藏，哪些内容必须第一眼出现。

对应的视觉风格见 `FRONTEND_MAIN_SCREEN_STYLE_FRAME.md`。

## 1. 目标

白描阶段只验证结构是否成立。

成功标准：

- 用户第一眼知道要放入视频或字幕文件。
- 用户知道当前会生成字幕交付包。
- 主操作清楚。
- 配置可见但不压迫主流程。
- 没有常驻导航、卡片墙、后台表格或后端流水线骨架。

## 2. 首屏固定对象

首屏只保留五个固定对象：

1. 少女助手位
2. 片源投递盒
3. 制作便签
4. 主动作
5. 交付包

允许一个轻状态文字区。

不放：

- 左侧导航。
- 顶部导航。
- 页面 tabs。
- 任务历史列表。
- provider 表格。
- 环境诊断列表。
- 统计数字墙。
- 完整流水线步骤。

## 3. 基础构图

首屏按“主对象居中、方案靠侧、输出靠尾”的逻辑组织。

```text
┌────────────────────────────────────────────────────────┐
│                                                        │
│  [少女助手位]                     [制作便签摘要]        │
│                                                        │
│                                                        │
│              ┌────────────────────────┐                │
│              │                        │                │
│              │      片源投递盒        │                │
│              │                        │                │
│              └────────────────────────┘                │
│                                                        │
│                    [主动作按钮]                         │
│                                                        │
│  [轻状态文字]                         [交付包]          │
│                                                        │
└────────────────────────────────────────────────────────┘
```

布局意图：

- 片源投递盒最大，承担首屏注意力。
- 制作便签是当前方案，不是设置页。
- 交付包提示输出目标，但空状态不抢主操作。
- 少女助手引导视线，不承担导航。
- 主动作在片源投递盒和交付包之间，表达从输入到输出。

## 4. 状态一：空状态

用户尚未选择文件。

```text
┌────────────────────────────────────────────────────────┐
│                                                        │
│  [少女助手：欢迎/指向投递盒]       [制作便签摘要]        │
│                                    日语 -> 简中         │
│                                    源字幕：自动         │
│                                    翻译：日常字幕方案   │
│                                    输出：SRT + ASS      │
│                                                        │
│              ┌────────────────────────┐                │
│              │                        │                │
│              │   放入视频或字幕文件   │                │
│              │                        │                │
│              └────────────────────────┘                │
│                                                        │
│                    [选择文件]                           │
│                                                        │
│  当前制作单会自动处理源字幕、翻译和交付格式。 [交付包]  │
│                                                        │
└────────────────────────────────────────────────────────┘
```

必须出现：

- `放入视频或字幕文件`
- `选择文件`
- 制作便签摘要
- 空交付包

不能出现：

- API key 输入框。
- provider 列表。
- ASR 参数。
- 任务历史。

## 5. 状态二：已放入片源

用户已经选择视频或字幕文件。

```text
┌────────────────────────────────────────────────────────┐
│                                                        │
│  [少女助手：就绪]                 [制作便签摘要]        │
│                                    日语 -> 简中         │
│                                    源字幕：自动         │
│                                    翻译：日常字幕方案   │
│                                    术语：项目词库       │
│                                    输出：SRT + ASS      │
│                                                        │
│              ┌────────────────────────┐                │
│              │  片源封套              │                │
│              │  example.mp4           │                │
│              │  视频 · 等待开始       │                │
│              └────────────────────────┘                │
│                                                        │
│                    [开始译制]                           │
│                                                        │
│  准备好后会生成字幕交付包。             [交付包：待生成] │
│                                                        │
└────────────────────────────────────────────────────────┘
```

必须出现：

- 文件名。
- 当前语言方向。
- 当前输出格式。
- 可用主按钮。

允许出现：

- 换文件。
- 打开制作便签。

默认不展开：

- ASR provider。
- 翻译 provider。
- 术语详情。
- 高级参数。

## 6. 状态三：制作便签展开

用户点击制作便签。

展开层不应变成完整设置页，只显示高频项。

```text
┌────────────────────────────────────────────────────────┐
│                                                        │
│  [少女助手位]                 ┌────────────────────┐    │
│                               │ 当前制作单          │    │
│                               │ 源语言：日语        │    │
│                               │ 目标：简体中文      │    │
│                               │ 源字幕：自动        │    │
│                               │ 翻译：日常字幕方案  │    │
│                               │ 术语：项目词库      │    │
│                               │ 输出：SRT + ASS     │    │
│                               │                    │    │
│                               │ [详细设置] [收起]   │    │
│                               └────────────────────┘    │
│              ┌────────────────────────┐                │
│              │       片源封套         │                │
│              └────────────────────────┘                │
│                                                        │
│                    [开始译制]                           │
│                                                        │
│  [轻状态文字]                         [交付包]          │
│                                                        │
└────────────────────────────────────────────────────────┘
```

高频项可以编辑：

- 源语言。
- 目标语言。
- 源字幕获取方式。
- 翻译方案。
- 术语是否参与。
- 输出格式。

详细设置入口才进入：

- API key。
- provider。
- base_url。
- ASR 本地服务地址。
- 模型列表。
- 连接测试。
- 高级运行参数。

## 7. 状态四：生成中

用户点击开始译制。

主屏不变成流水线页面。

```text
┌────────────────────────────────────────────────────────┐
│                                                        │
│  [少女助手：处理中]             [制作便签摘要，只读]    │
│                                                        │
│              ┌────────────────────────┐                │
│              │  片源封套              │                │
│              │  example.mp4           │                │
│              │  正在生成字幕          │                │
│              └────────────────────────┘                │
│                                                        │
│              正在获取源字幕，之后会自动翻译并整理交付包。│
│                    [查看事件] [取消]                    │
│                                                        │
│                                      [交付包：生成中]   │
│                                                        │
└────────────────────────────────────────────────────────┘
```

允许：

- 一句当前状态。
- 轻进度表现。
- 查看事件。
- 取消。

不允许：

- 常驻六阶段流水线。
- dashboard 指标墙。
- 日志默认铺满首屏。

## 8. 状态五：完成

任务完成。

视觉焦点从片源投递盒转向交付包。

```text
┌────────────────────────────────────────────────────────┐
│                                                        │
│  [少女助手：完成]               [制作便签摘要]          │
│                                                        │
│              ┌────────────────────────┐                │
│              │  example.mp4           │                │
│              │  字幕已生成            │                │
│              └────────────────────────┘                │
│                                                        │
│                    [再做一个]                           │
│                                                        │
│  字幕已整理好。                       ┌──────────────┐  │
│                                      │ 交付包        │  │
│                                      │ SRT  打开     │  │
│                                      │ ASS  打开     │  │
│                                      │ 检查字幕      │  │
│                                      │ 重新导出      │  │
│                                      └──────────────┘  │
│                                                        │
└────────────────────────────────────────────────────────┘
```

必须突出：

- 输出文件。
- 打开文件。
- 检查字幕。

任务历史不是完成状态主入口。

## 9. 状态六：失败

只展示当前阻塞问题。

```text
┌────────────────────────────────────────────────────────┐
│                                                        │
│  [少女助手：提示问题]           [制作便签摘要]          │
│                                                        │
│              ┌────────────────────────┐                │
│              │  example.mp4           │                │
│              │  需要处理              │                │
│              └────────────────────────┘                │
│                                                        │
│              ┌────────────────────────┐                │
│              │ 修理贴                 │                │
│              │ 无法获取源字幕          │                │
│              │ 本地 ASR 没有启动，     │                │
│              │ 也没有检测到内置字幕轨。│                │
│              │ [改用远端 ASR]         │                │
│              │ [选择已有字幕文件]      │                │
│              │ [查看诊断]             │                │
│              └────────────────────────┘                │
│                                                        │
│                                      [交付包：未生成]   │
│                                                        │
└────────────────────────────────────────────────────────┘
```

必须出现：

- 人能理解的问题标题。
- 当前影响。
- 直接修复动作。

默认不出现：

- 完整环境诊断表。
- 原始异常堆栈。
- provider 全量配置。

## 10. 进入下一阶段的条件

白描通过后，再进入高保真 style frame。

通过标准：

- 不看颜色和插画，也能理解主流程。
- 首屏不是配置表单。
- 制作便签承担配置摘要。
- 完成状态突出交付包。
- 失败状态突出修复动作。
- 没有自然滑回旧 desktop 页面结构。

如果白描阶段就像后台，不允许靠插画或颜色补救。
