# 2026-05 Web Workbench Failure Archive

本目录保存 2026 年 5 月这一轮前端实验的旧文档。

归档原因：

> 这一轮设计虽然试图描述“低光字幕制作工作台”，但实现和文档惯性把界面推向了 Web 管理台：左栏、顶栏、面板墙、状态徽标、圆角卡片和通用图标组合逐渐取代了真正的字幕创作/审校画面。

这些文档保留历史价值，但不再具备当前规范地位。

## 文件说明

- `FRONTEND_DESIGN_STYLE.md`
  - 旧视觉方向文档。
  - 其中部分产品语义仍可参考，但视觉结构已经失效。
- `FRONTEND_DEVELOPMENT_PLAN.md`
  - 旧阶段计划。
  - 它默认沿着多页面工作台继续推进，已不适合作为后续计划。
- `FRONTEND_IMAGE_PROMPTS.md`
  - 旧生图提示。
  - 它仍可作为反例和素材参考，但不能继续约束视觉探索。

## 禁止用法

不要从这些文档中恢复以下方向：

- “左侧导航 + 顶部任务状态 + 中央工作区 + 右侧检查面板”作为默认框架。
- `SectionPanel` 式页面拼装。
- 圆角卡片网格。
- 卡片嵌套卡片。
- 管理台式状态徽标和统计块。
- 以 Linear、VS Code、Notion、SaaS dashboard 作为默认参考。
- 先建组件系统，再让设计服从系统。

需要重新使用其中某个观点时，必须先用 `docs/FRONTEND/current/FRONTEND_DESIGN_SPEC.md` 校验。
