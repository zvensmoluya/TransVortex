# TransVortex 运行与测试指南

本指南用于在本地把 TransVortex 跑起来，并完成基础测试。

## 1. 环境要求

- 操作系统: Windows / macOS / Linux
- Python: 3.10+
- FFmpeg / FFprobe: 已加入 PATH

先确认版本:

```powershell
py --version
ffmpeg -version
ffprobe -version
```

如果 `py --version` 显示 3.9.x，请安装 Python 3.10 或更高版本后再继续。

## 2. 创建虚拟环境并安装依赖

在项目根目录执行:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -U pip
pip install -e .[asr,test]
```

说明:
- `asr` 依赖用于 `faster-whisper`
- `test` 依赖用于运行 `pytest`

## 3. 配置 API Key

项目默认读取 `providers.yaml` 中 `env_key` 对应的环境变量。

示例（PowerShell）:

```powershell
$env:ANTHROPIC_API_KEY = "你的key"
$env:GEMINI_API_KEY = "你的key"
```

如果你只用一个 provider，只设置对应 key 即可。

## 4. 运行单元测试

在虚拟环境内执行:

```powershell
python -m pytest -q
```

如果你只想先跑核心测试:

```powershell
python -m pytest -q tests/test_config.py tests/test_chunk_align.py tests/test_provider_factory.py
```

## 5. 跑一次端到端（E2E）

准备一个本地视频，例如 `demo.mp4`，然后执行:

```powershell
transvortex run --input demo.mp4 --src en --tgt zh-CN --bilingual
```

可选参数示例:

```powershell
transvortex run --input demo.mp4 --src en --tgt zh-CN --chunk-seconds 60 --translation-batch-size 40 --concurrency 8
```

任务运行后会在 `artifacts/<task_id>/` 下生成中间产物与输出字幕。

## 6. 查看状态与断点续跑

```powershell
transvortex status --task-id <task_id>
transvortex resume --task-id <task_id>
```

## 7. 快速自检清单

- `python -m pytest -q` 通过
- `transvortex run ...` 能生成 `.srt`
- `transvortex status --task-id ...` 返回 `DONE`
- 输出目录下可看到 `segments.final.json` 和最终字幕文件

## 8. 常见问题

- 报错: `No module named pytest`
  - 原因: 没安装测试依赖
  - 处理: `pip install -e .[test]`

- 报错: `faster-whisper is required for ASR`
  - 原因: 没安装 ASR 依赖
  - 处理: `pip install -e .[asr]`

- 报错: `Missing environment variable: XXX`
  - 原因: 未设置对应 API Key
  - 处理: 按 `providers.yaml` 的 `env_key` 设置环境变量

- 报错: 找不到 `ffmpeg` 或 `ffprobe`
  - 原因: 没安装或未加入 PATH
  - 处理: 安装 FFmpeg 并重开终端

- 报错: Python 版本不满足
  - 原因: 当前解释器低于 3.10
  - 处理: 安装 Python 3.10+，并用 `py -3.10` 创建虚拟环境
