# TransVortex 运行与测试指南（简化版）

这份文档只保留一条目标：**让你最快确认项目能跑**。

## 0. 前置条件（一次性）

- Python 3.10+
- `ffmpeg`、`ffprobe` 在 PATH 中
- 已有可用的 `providers.local.yaml`

可用下面命令快速确认：

```powershell
py --version
ffmpeg -version
ffprobe -version
```

## 1. 三步跑通（推荐）

在项目根目录执行：

```powershell
# 第1步：进入虚拟环境
.\.venv\Scripts\Activate.ps1

# 第2步：设置 API Key（当前终端会话）
$env:VECTORENGINE_API_KEY = "YOUR_API_KEY"

# 第3步：先预检，再跑测试
transvortex probe-provider --providers-file .\providers.local.yaml --strict
python -m pytest -q
```

如果你看到 `12 passed`（或全部通过），说明基础测试已通过。

## 2. 跑一次端到端（可选）

准备一个本地视频（例如 `demo.mp4`）：

```powershell
transvortex run --providers-file .\providers.local.yaml --input demo.mp4 --src en --tgt zh-CN --bilingual
```

输出会在 `artifacts/<task_id>/` 下，通常关注 `.srt` 文件即可。

## 3. 常用排错（只看这几条）

- `No module named pytest`
  - 执行：`python -m pip install -e .[test]`
- `faster-whisper is required for ASR`
  - 执行：`python -m pip install -e .[asr]`
- `Missing environment variable: VECTORENGINE_API_KEY`
  - 说明当前终端没设 key，重新执行 `$env:VECTORENGINE_API_KEY = "..."`
- 找不到 `ffmpeg` / `ffprobe`
  - 说明 PATH 未生效，安装后重开终端

## 4. 备用：从零创建环境（仅在 `.venv` 不可用时）

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -U pip
pip install -e .[asr,test]
```
